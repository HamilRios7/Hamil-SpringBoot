# API de Gestión de Libros - Spring Boot

Aplicación backend desarrollada con Spring Boot y persistencia en base de datos Oracle, diseñada para gestionar el inventario de una librería siguiendo un flujo de trabajo profesional con DevOps.

## Tecnologías utilizadas

* Java 17
* Spring Boot
* Spring Web (API REST)
* Spring Data JPA
* Spring Security
* SpringDoc OpenAPI (Swagger)
* Oracle Database

## Ramas del Proyecto

* **develop**: Rama de trabajo activo para el desarrollo de nuevas funcionalidades.
* **main**: Rama estable con la versión final del proyecto.
